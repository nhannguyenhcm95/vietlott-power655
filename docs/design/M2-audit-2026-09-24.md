## Data facts verified during the audit (read-only)

- **Gaps between draws.** The curated draws have gaps of 2 days (×925), 3 days (×463), 4 days (×3), 5 days (×7), 25 days (×1) and 28 days (×1).
  - Twelve gaps skip at least one scheduled Tue/Thu/Sat.
  - Ten of those skip exactly one draw: nine are around Tết, and one is 00468→00469 (2020-08-25 → 08-29), which is not Tết.
  - The two suspensions skip 10 draws (00415→00416) and 11 draws (00608→00609).
- **Mirror timing.** The mirror's `process_time` is about 00:01 on the day after the draw, so its lag is 1 at the 20:00 run and 0 at the 08:30 retry.
- **Duplicate content.**
  - The probability that some pair of draws shares both the main set and the special number is 6.9e-4.
  - The probability that some pair shares the main set alone is 3.3%.
  - One real pair does: 00647 and 00993 both have 8-19-27-34-46-51, with specials 2 and 24.
- **Reproducibility.** Recomputing from curated gives `ds_cbdf3834368e`, but only when `special_number` is read as Int64.

## Findings

1. **BLOCKER: KI-001 approval.** The note seeds KI-001 as proposed, which conflicts with the human approval. The field name must be `approved_on`.
   - Add a transcription rule: an agent may fill approval fields only by copying a decision recorded in TASKBOARD Decisions, and the entry must include `approval_ref`. data-qa cross-checks this.
   - Rewrite §1.5-4. With KI-001 approved on real data, the result is PASS and 00944 is listed as accepted. On a temporary copy with the approval blanked, the result is WARN on exactly three checks.
   - Rewrite §2.8-6 to expect exit 0.
2. **MAJOR: known issues can hide failures.**
   - (a) Validate entries with an allowlist: `source` must be in SOURCES, `draw_id` must match `^\d{5}$`, and `rule` must come from the published vocabulary. Anything else is FAIL.
   - (b) These rules can never be accepted: `curated.schema`, `curated.lineage`/`curated_matches_staging`/`raw_lineage`/`frozen_prefix`, `raw.checksums`, `known_issues_file`, `retrieved_after_draw`, and duplicate draw_id or draw_date in official data.
   - (c) A date range may be used only with rules that have no draw_id (`freshness`). It must end on or before `review_by`, span at most 60 days, and be matched per missed scheduled date, with one freshness finding per missed date.
   - (d) Accepting a FAIL-level finding (field mismatch, `stored_row_conflict`) must pin the expected values.
   - (e) An entry past `review_by` stops accepting findings and raises a WARN on `known_issues.file`.
   - (f) An entry with `approved_on` after `as_of` counts as proposed.
   - (g) If the file is absent, report INFO. If it is malformed, report FAIL.
3. **MAJOR: finding names are undefined.** Add a table giving the `rule` string and `source` for every finding.
   - Reconcile findings take the source that is missing or disagreeing: `only_left` → the right source, `only_right` → the left source, field mismatch → `github_mirror`.
   - The vocabulary lives in `known_issues.py`.
4. **MAJOR: official empty fetch** is FAIL (see D3). The mirror stays WARN.
   - A source "has stored rows" if any earlier `ingestion_log` run had `rows_inserted > 0`. Runs with `--start`/`--end` do not count.
   - The CLI rejects `--start`/`--end` in incremental mode.
5. **MAJOR: exit codes and the scheduler environment.** Exit codes are set by D1.
   - The action is `powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File <abs>\scripts\run_refresh.ps1 -PythonExe <resolved>`, with WorkingDirectory set to the project root.
   - The script runs `Set-Location $PSScriptRoot\..`.
   - Set `$ErrorActionPreference='Continue'` around the native call, then `exit $LASTEXITCODE`. In PS 5.1, stderr combined with Stop throws.
   - Use `-AllowStartIfOnBatteries -DontStopIfGoingOnBatteries`.
   - `run_refresh.ps1` maps any unexpected exit code, or a run without the final RefreshResult JSON line, to 50.
6. **MAJOR: tests pollute the real data/ directory.** Use `main(argv, paths: Paths | None = None)` or a `POWER655_ROOT` override.
   - All CLI tests use the `paths` fixture.
   - Add a guard test that the real `data/logs` mtime does not change.
7. **MAJOR: blocking on mismatch.** Resolved by D2. `test_mismatch_blocks_curate` must use the realistic sequence: an official draw at 20:00, then a mirror mismatch at 08:30.
8. **MAJOR: lineage and freeze.**
   - (a) `raw_lineage` re-parses each referenced raw run offline with `source.parse`. Every staging row must equal a parsed record from its `raw_run_id`.
   - (b) Add `frozen_prefix` (D5).
   - (c) A wrong first draw is FAIL.
9. **MAJOR: fixtures and absent inputs.**
   - Build fixtures by running `run_ingestion` on FakeSession sources for both `vietlott_official` and `github_mirror`. Set `as_of` just after the last fixture draw.
   - Status table for absent inputs:

     | Absent input | Status |

     | ingestion_log | FAIL |

## Re-audit of Revision 2 (2026-09-24): verdict REWORK, small scope

All 19 findings and D1–D6 are resolved, except the items below. Judgement calls (a), (b) and (c) are accepted, with (b) conditional on N2 and (c) conditional on N6.

1. **N1 (MAJOR).** `mirror_shrink` becomes WARN (exit 10), which is consistent with D3.
   - Evaluate it only when `received` is non-empty. An empty fetch is covered by `incremental_empty_fetch`.
   - Rename the test to `test_mirror_shrink_warn_exit10`.
2. **N2 (MINOR).** `stored_row_conflict` can never be accepted as a known issue for the official source. For the mirror it can be accepted without a pin.
   - The finding becomes RESOLVED when a later run of the same source includes that draw_id in `received_ids()` and logs no conflict for it.
3. **N3 (MINOR).** The guard for real data compares a recursive snapshot of every file under `data/` and `reports/`: relative path, size and `mtime_ns`. Directory mtimes are not enough.
4. **N4 (MINOR).** The `frozen_prefix` gate also applies to the manual `curate` CLI. On failure it exits 30 and writes nothing.
5. **N5 (MINOR).** `refresh --as-of` works only in tests (with an injected source factory or paths). Otherwise, reject an `as_of` earlier than now minus 1 hour.
6. **N6 (MINOR).** A missing quality_log is INFO only if no ingestion run is `partial`. If a run is partial, report a `log_integrity` finding: WARN when the run is from the mirror, FAIL when it is from the official source.
7. **N7 (MINOR).** Replace "manifest ids" with "the draw_ids of `read_fact_draw(curated)`".
8. **N8 (MINOR).** A pin must equal the finding's `observed` JSON exactly, as string values.
   - Add a test in which an integer pin is not accepted.
9. **N9 (MINOR).**
   - A date-range known issue becomes INFO, not WARN, once `as_of > draw_date_to`.
   - The register script rejects a `\WindowsApps\` python. It checks `& $PythonExe -c "import pandas, bs4, src.cli"` from the project root.
